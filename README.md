# FirstRung

A curated directory of structured graduate programs in the United States and Canada.

The site lives in [`site/`](site/README.md). Run `cd site` followed by `npm start` to preview at http://127.0.0.1:4173. No dependency installation is required. Run `npm test` from that directory to verify filtering, eligibility and the 14-day closure lifecycle.

The initial directory contains 21 employer-sourced program entries. It distinguishes confirmed openings from program overviews with unconfirmed availability. See the site README for sourcing limitations and the editorial maintenance workflow.

Hosting was registered, but publication was not completed. The local preview is the current deliverable.
